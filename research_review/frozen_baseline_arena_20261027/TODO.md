# Frozen-baseline arena

- [x] Frame. Define the question, shared evidence, output, and scoring criteria.
- [x] Fan out. Three independent baseline-selection proposals completed.
- [ ] Cross-judge. A separate reviewer scores the completed proposals.
- [ ] Pick. Read every proposal and score it against the same criteria.
- [ ] Graft. Combine the strongest justified choices into one plan.
- [ ] Verify. Check the plan against repository evidence and primary sources.

Scope assumption: choose methods for combining the existing five frozen forecasters. The user has been asked whether they meant the forecasters themselves.

No research training, server runs, test-block access, source edits in the main research repository, commits, or changes to prior experiment readings are part of this task.

The arena skill's preferred Claude and Grok models are unavailable. Candidates and judge use independent sessions of the available parent model. This is independent review, not a comparison between model families.
